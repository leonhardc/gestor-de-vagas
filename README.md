# Gestor de Vagas

Um sistema web desenvolvido para ajudar pessoas que estão procurando emprego a organizar e acompanhar suas candidaturas.

O projeto permite cadastrar vagas, empresas, etapas do processo seletivo, contatos e acompanhar o status de cada candidatura em um só lugar.

**Tecnologias:** Python, Django, PostgreSQL, HTML, CSS e JavaScript.
